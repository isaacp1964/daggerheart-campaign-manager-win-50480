## About Daggerheart Campaign Manager

Daggerheart Campaign Manager is a web tool designed to help game masters keep track of their Daggerheart games in one place. It focuses on campaign organization, world-building support, and everyday GM planning so you can spend less time juggling notes and more time running sessions.

It is built for GMs who manage more than one campaign or want a central workspace for setting details, story threads, and table prep. The interface and workflow are aimed at practical campaign oversight, making it easier to structure information and revisit it when sessions move forward.

## Usage

After opening the app, create a campaign and begin adding the details you want to track. A typical workflow looks like this:

1. Start a new campaign record
2. Add world-building notes for locations, factions, NPCs, or plot ideas
3. Organize information by campaign so each game stays separate
4. Revisit entries during session prep and update them as the story changes

For day-to-day GM work, use the tool as a reference hub for campaign context and planning material.
